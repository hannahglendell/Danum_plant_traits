CREATING A DATABASE OF REPRODUCTIVE PLANT TRAITS

This repository contains all of the code and datafiles used to create a database of reproductive traits of trees found in the Danum Valley Conservation Area. It covers the work undertaken in my 8-week Research Experience Placment at UKCEH.

In general, the folders are intuitively named, but here is a brief explanation:

- 'R scripts' folder contains all of the .Rmd files used. 
- 'Botanic gardens list' covers what I did in my visit to the botanic gardens
- 'Processed trait data' contains an individual dataset for each trait, complete with references. 'all traits database.csv' is the final plant traits database with all of the plant traits.
- 'raw trait data' contains unprocessed trait data.
- 'size at reproductive maturity' contains the raw data used to extract information of size at reproductive maturity.
- 'species list data' contains the raw field data used to compile the species list, as well as a number of intermediate species lists that I made on the way to making the final species list. 'final species list uncorrected' is the final species list BEFORE all species names were corrected against POWO. 'final species list with corrected names' is the species list once species names were checked and corrected against POWO. 'final species list corrected and cleaned' is the final species list once any duplicates (which appeared during cleaning) had been removed.
